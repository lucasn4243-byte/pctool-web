Questions fréquentes (FAQ)

❓ PC Tool est-il vraiment gratuit ?

Oui, PC Tool est 100% gratuit ! Il n'y a aucun frais caché, aucun abonnement, et toutes les fonctionnalités sont accessibles gratuitement. Le logiciel est financé par de la publicité non intrusive sur notre site web.

🛡️ PC Tool contient-il des virus ou malwares ?

Non, PC Tool est totalement sûr. Le logiciel est régulièrement scanné par Windows Defender et VirusTotal. Nous ne collectons aucune donnée personnelle et le code est propre. Certains antivirus peuvent signaler de fausses alertes car PC Tool modifie des fichiers système (registre, démarrage), mais c'est normal pour un logiciel de maintenance.

💻 Sur quels systèmes PC Tool fonctionne-t-il ?

Windows 10 et Windows 11 (32 bits et 64 bits). PC Tool nécessite des droits administrateur pour fonctionner correctement car il effectue des opérations système avancées.

⚙️ Pourquoi mon antivirus bloque PC Tool ?

C'est une fausse alerte (faux positif). PC Tool modifie le registre Windows et accède à des fichiers système, ce qui peut déclencher des alertes de sécurité. Vous pouvez ajouter PC Tool à la liste des exceptions de votre antivirus. Le logiciel est sûr et ne contient aucun code malveillant.

🔑 Comment créer une clé USB Windows 11 sans TPM 2.0 ?

Utilisez l'option "Windows 11 Bypass TPM". Dans l'onglet "Media Creation Windows", sélectionnez "Windows 11 Bypass TPM", puis cliquez sur "Installer directement (Setup)". PC Tool téléchargera automatiquement un script de contournement officiel et lancera l'installation Windows 11 même sur des PC sans TPM 2.0.

🧹 Le nettoyage supprime-t-il des fichiers importants ?

Non, PC Tool ne supprime que les fichiers temporaires et inutiles. Le logiciel cible uniquement les caches, fichiers temporaires Windows, et corbeille. Vos documents, photos, et fichiers personnels ne sont jamais touchés. Pour le registre, une sauvegarde est toujours créée avant modification.

💾 Puis-je annuler une opération en cours ?

Oui, utilisez le bouton "Annuler" rouge. PC Tool permet d'annuler la plupart des opérations longues (téléchargement ISO, création de clé USB, scan antivirus). Un nettoyage automatique des fichiers temporaires est effectué en cas d'annulation.

🔄 Comment mettre à jour PC Tool ?

Les mises à jour seront automatiques. Dans les prochaines versions, PC Tool vérifiera automatiquement les mises à jour au démarrage et vous proposera de télécharger la dernière version si disponible.

🗑️ Comment désinstaller PC Tool ?

Via le panneau de configuration Windows. Allez dans Paramètres → Applications → PC Tool → Désinstaller. Vous pouvez aussi utiliser l'onglet "Désinstalleur de programme" de PC Tool lui-même !
